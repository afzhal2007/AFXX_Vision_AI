## 🔧 Easy Customization

### Change Colors
Edit `static/style.css`:
```css
--primary-color: #your_color;
--secondary-color: #your_color;
```

### Adjust Detection Sensitivity
Edit `app.py`:
```python
result = detector.detect_frame(frame, conf_threshold=0.50)
```

### Use Different AI Model
Edit `detector.py`:
```python
self.model = YOLO("yolov8m.pt")  # Change to s, m, l, x
```

### Disable Animations
Add to `style.css`:
```css
* { animation: none !important; }
```
