## 🔧 EASY CUSTOMIZATION

### Change Theme Color
**File**: `static/style.css`
```css
--primary-color: #your_color;
```

### Adjust Detection Sensitivity
**File**: `app.py` (Line 45)
```python
conf_threshold=0.50  # Lower = more detections
```

### Use Different AI Model
**File**: `detector.py` (Line 14)
```python
YOLO("yolov8m.pt")  # Choose: n, s, m, l, x
```

### Disable Animations
**File**: `static/style.css` (Add)
```css
* { animation: none !important; }
```
